# 스프링 세팅을 숫자로 비교하다

> 01 / VEHICLE DYNAMICS · 2026년 10월 기준

Formula Student 차량의 서스펜션 담당자로서, 전륜 스프링 레이트 변경이 실제 차량의 롤 응답에 어떻게 나타나는지 확인했습니다.

| 항목 | 내용 |
|---|---|
| 7회 | 변경 전 2회 + 변경 후 5회 |
| 250 → 300 | 전륜 스프링 · lb/in |
| 약 7.4% | 전륜 롤 기울기 감소 관찰 |

## 무엇을 비교했나요?

후륜 스프링 300 lb/in과 후륜 안티롤바 설정을 유지한 상태에서 전륜 스프링을 250에서 300 lb/in으로 변경했습니다. 서스펜션 변위와 횡가속도 데이터를 통해 준정상 선회에서의 롤 기울기를 비교했습니다.

## 제가 맡은 일

- 직접 주행과 서스펜션 세팅, 계측팀이 제공한 원시데이터의 분석을 수행했습니다.
- 손계산·해석과 실측값을 비교하며 세팅 판단의 근거를 정리했습니다. 센서 로깅은 계측팀의 역할이었고 프로그래밍 작업에는 도움을 받았습니다.

## 관찰한 결과

전륜 롤 기울기는 1.182에서 1.095 deg/g로 약 7.4% 감소했습니다. 후륜은 1.031에서 1.045 deg/g로 약 1.3% 증가했습니다. 필터 2~5 Hz 범위에서 전륜 감소율은 약 7.1~7.4%였습니다.

## 결과와 함께 남긴 한계

변경 전후를 순차적으로 주행한 시험으로, 타이어 온도·공기압, 노면과 운전자 입력의 영향을 완전히 분리하지 못했습니다. 이 수치를 랩타임이나 접지력 개선으로 해석하지 않았습니다. A-B-A 시험과 안티롤바·댐퍼 확장 검증은 후속 과제입니다.
