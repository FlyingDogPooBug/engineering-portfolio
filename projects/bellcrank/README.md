*최적화 결과를 바탕으로 재설계한 전륜 벨크랭크 플레이트 CAD*

## 설계에서 제작까지

- Altair Inspire의 위상최적화 결과를 바탕으로 하중 전달 경로를 검토했습니다.
- 체결 홀 주변을 보존하고 판재로 제작할 수 있도록 형상을 수정했습니다.
- SolidWorks로 형상을 구체화하고 ANSYS로 구조를 검토한 뒤 제작했습니다.

## 숫자를 구분해 기록했습니다

보고서의 CAD 비교값은 전륜 51.21 → 26.25 g, 후륜 58.13 → 28.27 g입니다. 제작품 저울 사진에 기록된 한 장의 무게는 전륜 25 g, 후륜 28 g입니다. CAD 질량 감소율을 실물 전후 비교 측정값으로 바꾸어 표현하지 않았습니다.

## 제작 기준을 지그에 담기

AEF-25부터 사용한 지그·로드엔드 방식을 유지하면서, 하드포인트를 제작물에 옮기는 체결 구조와 절차를 검토했습니다. 보고서에는 5T 철판 지그에 체결부를 고정한 뒤 가접·치수 확인·본용접을 진행하고, 우나사·좌나사 로드엔드로 푸시로드 길이를 조절하는 제작 절차를 정리했습니다.

해석 결과의 형상을 그대로 따르기보다, 하중이 전달되는 영역과 제작·조립 조건을 함께 고려해야 했습니다. 설계 판단이 실제 부품에 어떻게 남는지 확인할 수 있었던 경험입니다.
