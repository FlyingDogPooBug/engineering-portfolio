> 05 / EXTERNAL COLLABORATION · 2026년 10월 기준

A-FA의 개발에 필요한 후원과 시험을 외부 파트너와 협의했습니다. 팀의 목적을 설명하고 기술 자료를 전달한 뒤, 결과 보고와 다음 담당자 소개까지 이어 가는 역할을 맡았습니다.

| 항목 | 내용 |
|---|---|
| 제안 | 필요한 지원과 개발 목적 정리 |
| 협의 | 제원·시험 조건·자료 전달 |
| 보고 | 시즌 결과와 후속 담당자 연결 |

## 시험 목적과 자료의 적합성을 확인하기

한국자동차연구원에 댐퍼 시험조건과 Excel 데이터 제공 여부를 문의하고, 제원·도면을 전달했습니다. 제공 자료가 차량 조건에 맞는지 검토해 보유 댐퍼의 실물시험 조건을 다시 문의했습니다. 네오테크에서는 보유 댐퍼의 다이나모 시험 완료 안내와 보고서를 수신했습니다. 제 역할은 기술 협의와 자료 검토이며 시험 수행은 외부 기관의 작업입니다.

## 제작 협의를 팀의 운영 방식으로 연결하기

MakeIT에 파트별 발주와 차기 팀 인수인계 방식을 제안하고 합의를 받았습니다. 벨크랭크의 제작 완료와 직접 전달 이후 부품 수령도 확인했습니다. 시즌 종료 후에는 후임이 견적을 요청할 방식까지 연결하고 업체의 확인 회신을 받았습니다.

## 실사용 자료와 시즌 결과로 답하기

- 써보레에는 용접 보호장비의 제작 현장 사용과 시즌 결과를 보고했습니다. 후원사는 보고서를 내부에 공유하고 다음 팀을 응원하는 회신을 보냈습니다.
- GB Industries에는 NOVAX 안전장갑의 사용·홍보 자료를 전달했습니다. 상대방이 사진·영상 수령과 팀의 제품 사용을 확인했습니다.
- Synology에는 NAS 활용과 시즌 자료를 보고하고 다음 담당자를 연결했습니다. KISSsoft에는 후임 팀장을 소개했고, 담당자 등록과 지원 지속 의사를 담은 회신을 받았습니다.

## 피드백을 다음 원고에 반영하기

Synology의 지원 장비를 설치한 뒤 활용 콘텐츠의 피드백을 조율했습니다. 실제 활용 장면이 드러나도록 팀원·사진동아리와 사진과 원고를 보완해 다시 전달했고, 최종 진행 승인을 받았습니다. 이후 Instagram·Facebook 게시물의 인사이트를 공유하고 후속 자료 요청에 응답했습니다. 제작은 협업으로 이루어졌으며 제 역할은 요구사항 정리, 수정 소통과 후속 보고입니다.

## 관계를 다음 시즌으로 넘기기

차기 팀장을 소개하고 상대방이 후속 담당자를 확인할 수 있도록 연결했습니다. KISSsoft의 기존 소프트웨어 지원 갱신과 담당자 승계도 챙겼습니다. SOLIDWORKS Student Sponsorship의 제공·설치 안내는 팀원과 후임에게 전달해 설계 환경에 필요한 정보가 이어지도록 했습니다.

## 영문으로 실무를 처리하기

해외 부품 주문 과정에서 공급 업체에 팀명으로 배송 정보 정정을 요청했습니다. 기술 협의뿐 아니라 실제 주문을 진행하며 필요한 영문 연락도 맡았습니다.
