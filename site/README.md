# Portfolio website source

[Live website](https://yongmin-engineering-portfolio-oct26.gardengnat12.chatgpt.site) · [Repository overview](../README.md)

Buildless HTML, CSS and JavaScript. Source and media mirror the public portfolio as of October 20, 2026.

```sh
python -m http.server 8000 --directory site
```

Open http://127.0.0.1:8000. No dependency installation or build is required. Korean and English content, case dialogs, competition filters and media work in the static site.

The canonical URL and sharing metadata point to the primary Sites publication. Hosting credentials, Site identity configuration and private research material are not part of this mirror.
