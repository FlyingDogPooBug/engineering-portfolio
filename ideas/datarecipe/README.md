> IDEAS / DATA EVALUATION · 2026년 10월 기준

2026 데이터+AI 혁신 챌린지에 제출한 0ERROR 팀의 데이터 레시피입니다. 공개 유압설비 데이터의 구간들이 학습·검증·시험 세트에 어떻게 나뉘는지 살펴보고, 원본 주기를 기준으로 평가 누수를 점검했습니다.

| 항목 | 내용 |
|---|---|
| 2,205 | 공개 데이터의 원본 주기 |
| 26,460 | 파생 구간 · 32개 센서 변수 |
| 0 | 주기별 분할 후 공유 주기 |

## 행이 달라도 같은 실험일 수 있습니다

한 운전주기를 여러 구간으로 나눈 뒤 행을 무작위로 분할하면, 같은 원본 주기의 일부가 학습과 시험에 동시에 들어갈 수 있습니다. 이 레시피에서는 구간을 원본 주기 식별자와 연결하고 분할 사이의 교집합을 점검했습니다.

## 확인한 산출물

전처리 데이터, 분할 감사 코드, 감사 결과와 포털 등록 원고를 준비했습니다. 저장된 CSV를 대조한 결과 행 무작위 분할의 학습·시험 공유 주기는 1,884개였고, 주기별 분할에서는 0개였습니다. AI 보조 작업으로 구성한 데이터 처리 절차와 결과를 문서화한 경험입니다.

## 접수와 검증 범위

2026년 10월 16일 포털의 제출완료 화면을 확인했습니다. 이 결과는 데이터 분할의 중복 점검이며 모델 탐지율 향상이나 0ERROR 자체 냉각 테스트베드의 실험 성과를 뜻하지 않습니다.
