## 분양 이후의 과정에 주목하기

자원 수령 후 실험에 착수하지 못하거나 중단하는 이유를 구분하고, 필요한 지원과 재개 여부의 확인으로 연결하는 운영 흐름을 설계했습니다.

## 어떤 산출물을 만들었나요?

공개된 자원 분양 절차와 사후 보고 흐름을 검토해 5쪽 제안서와 참고자료 묶음으로 정리했습니다. 자원 수령, 상황 확인, 담당자 지원과 재개 확인을 잇는 서비스 개념입니다.

## 제안의 현재 단계

제안서와 본인 명의 서약서가 확인됩니다. 기관 도입, 이용자 면담이나 실험 착수율 개선을 완료한 운영 실적으로 제시하지 않습니다.
