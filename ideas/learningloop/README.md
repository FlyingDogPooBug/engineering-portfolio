# 실패를 데이터로 바꾸는 법

[포트폴리오 처음으로](../../README.md) · [English](README.en.md) · [웹 포트폴리오](https://yongmin-engineering-portfolio-oct26.gardengnat12.chatgpt.site/#ideas)

> IDEAS / LEARNING CONTENT · 2026년 10월 기준

2025-2학기 온라인 학습법 콘텐츠 개발을 위해, 공학 프로젝트의 실패를 기록·회고·개선으로 연결하는 학습 자료를 제작했습니다.

| 항목 | 내용 |
|---|---|
| 3차시 | PDF 학습 자료 |
| 기록 | Failure Log |
| 회고 | AAR와 개선 루프 |

## 자료의 구성

1차시에서는 실패를 학습 데이터로 바라보는 관점, 2차시에서는 기록과 팀 회고, 3차시에서는 반복되는 문제의 우선순위와 개선 루프를 설명했습니다.

## 제가 만든 산출물

강의 시나리오와 1·2·3차시 학습 자료를 작성했습니다. 기록할 항목과 회고 질문, 개선을 다음 실행으로 연결하는 절차를 교육용 예시와 함께 구성했습니다.

## 콘텐츠 제작의 범위

3차시 자료가 존재하는 것과 실제 강의 촬영·배포·수강 운영은 구분합니다. 슬라이드의 교육용 사례나 성적·시간 변화를 제 개인의 검증된 성과로 옮기지 않았습니다.
