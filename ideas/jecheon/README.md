> IDEAS / PUBLIC DATA & POLICY · 2026년 10월 기준

2026 제천시 AI 활용 데이터 분석 아이디어 공모전을 위한 팀 작업입니다. 0ERROR 팀의 제조업 데이터 분석을 단계적인 설비관리 실증지원 정책으로 연결했습니다.

| 항목 | 내용 |
|---|---|
| PM | 총괄 기획·보고서 통합 |
| 팀 작업 | 데이터 분석과 역할 분담 |
| 정책안 | 현장 실증지원 제안 |

## 분석에서 정책으로

공장등록과 기업체 현황을 산업단지·업종 관점에서 살펴보고, 냉각설비 실증지원 대상을 검토하는 방안을 제안했습니다. 팀의 분석 결과가 누구를 어떤 단계로 지원할지에 연결되도록 정리했습니다.

## 제가 맡은 일

역할표에 기재된 제 담당은 총괄 PM, 정책 기획, 보고서 통합과 발표입니다. 데이터 분석·AI 검증, 센서·회로와 열유체 해석은 팀 내 역할을 구분해 기록했습니다.

## 현재 산출물의 범위

분석 보고서·요약서와 신청서를 작성하고 2026년 10월 12일 팀 대표로 이메일 제출했습니다. 제천시의 정책 채택이나 기업 현장 실증을 완료했다는 의미는 아닙니다. 기존 0ERROR의 냉각진단 구상을 정책에 적용한 작업이며, 별도의 제품 개발 성과로 세지 않습니다.
